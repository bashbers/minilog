# Minilog

Minilog is a privacy-first, self-hosted baby-care log designed for fast, one-handed use on mobile devices. It is an installable React PWA backed by FastAPI, SQLAlchemy, and SQLite, distributed with Docker Compose.

The repository currently contains an agreed, implementation-ready design. Application code has not been scaffolded yet.
