# Import PiyoLog text through an auditable, tolerant pipeline

The MVP will import English and Japanese PiyoLog day or month text exports through upload, parse, preview, and explicit confirmation. Because the documented exports lack stable record IDs, UTC offsets, complete authorship, photos, and some account data, Minilog will preserve provenance and unknown source lines, reconcile available daily totals, and report limitations instead of claiming a lossless clone; PDFs, photos, account settings, and the short-history QR notation are excluded.
